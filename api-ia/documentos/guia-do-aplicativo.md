# Guia do aplicativo Entrelinhas

## Registrar um humor
Na tela Início, toque em Criar humor ou na aba Registrar. Selecione o humor que melhor representa o momento. Salvar registro rápido grava o humor selecionado. Complementar registro abre as opções de data, hora e atividades, seguidas de um campo de texto opcional.

## Encontrar e editar registros
No Calendário, toque no dia do registro para filtrar a lista. Abra Ver detalhes e use Editar registro para corrigir os campos ou Excluir registro para apagar uma entrada. O app pede confirmação para excluir.

## Entender o gráfico
Em Estatísticas, use Anterior e Próximo para escolher o mês. Cada barra corresponde a um humor. A altura e o número mostram quantos registros daquele humor foram feitos no mês. Um mesmo dia pode ter mais de um registro. As barras descrevem a frequência dos registros daquele mês.

## Exportar os dados
Abra Ajustes, depois Privacidade e dados e Exportar meus dados. Escolha o relatório do mês ou do histórico completo. No Android, selecione uma pasta como Documentos e confirme em Usar esta pasta. Se o app oferecer Abrir impressão, use Salvar como PDF no menu do sistema.

## Usar a conversa
A conversa serve para tirar dúvidas sobre o app e buscar perguntas gerais para refletir por conta própria. Envie perguntas gerais. Deixe nomes, contatos, diagnósticos e detalhes íntimos fora da conversa. O app encaminha a pergunta à API de IA, que consulta o Gemini.
